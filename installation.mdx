## Requirements

- **Go 1.24 or later** — `summarize` is built for Go 1.24.0 and uses standard Go tooling.

<Tip>
After installing, confirm that `$(go env GOBIN)` is in your `$PATH`. If `summarize` is not found after installation, run `export PATH="$(go env GOBIN):$PATH"` and add that line to your shell profile.
</Tip>

## Install

<Steps>
  <Step title="Install with go install">
    The fastest way to install `summarize` is with a single command:

    ```bash
    go install github.com/andreimerlescu/summarize@latest
    ```

    Go downloads, compiles, and places the binary in `$(go env GOBIN)`.
  </Step>

  <Step title="Verify the installation">
    Confirm the binary is available and check the version:

    ```bash
    summarize -v
    ```

    Expected output:

    ```
    v1.1.1
    ```
  </Step>
</Steps>

## Install options

<CodeGroup>

```bash go install
go install github.com/andreimerlescu/summarize@latest
```

```bash build from source
git clone https://github.com/andreimerlescu/summarize.git
cd summarize
make darwin-arm64   # macOS Apple Silicon
make darwin-amd64   # macOS Intel
make linux-amd64    # Linux x86-64
make linux-arm64    # Linux ARM64
make windows-amd64  # Windows x86-64
make install        # copy binary to $(go env GOBIN)
```

</CodeGroup>

## Makefile targets

When building from source, the Makefile produces stripped binaries (`-ldflags "-s -w"`) in a `bin/` directory:

| Target | Output | Platform |
|---|---|---|
| `darwin-amd64` | `bin/summarize-darwin-amd64` | macOS Intel |
| `darwin-arm64` | `bin/summarize-darwin-arm64` | macOS Apple Silicon |
| `linux-amd64` | `bin/summarize-linux-amd64` | Linux x86-64 |
| `linux-arm64` | `bin/summarize-linux-arm64` | Linux ARM64 |
| `windows-amd64` | `bin/summarize.exe` | Windows x86-64 |
| `all` | all of the above + `install` | all platforms |
| `install` | copies binary to `$(go env GOBIN)` | current platform |

After running a platform target, run `make install` to copy the compiled binary to your `GOBIN` directory.
