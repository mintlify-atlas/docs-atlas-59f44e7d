---
title: "Quickstart"
description: "Generate your first project summary in under a minute"
---

<Steps>
  <Step title="Install summarize">
    Install the binary with a single command:

    ```bash
    go install github.com/andreimerlescu/summarize@latest
    ```

    Confirm it is available:

    ```bash
    summarize -v
    ```

    Output:

    ```
    v1.1.1
    ```
  </Step>

  <Step title="Navigate to your project and run summarize">
    Change into the directory you want to summarize, then run the tool with no arguments:

    ```bash
    cd ~/work/myproject
    summarize
    ```

    `summarize` defaults to scanning `.` (the current directory) and writing output to `./summaries/`.
  </Step>

  <Step title="Find the generated file">
    When the run completes, `summarize` prints the path to the new file:

    ```
    Summary generated: summaries/summary.2025.07.29.08.59.03.UTC.md
    ```

    The filename uses the timestamp format `YYYY.MM.DD.HH.MM.SS.UTC.md`, so every run produces a unique file. List the directory to confirm:

    ```bash
    ls -la summaries/
    ```
  </Step>

  <Step title="Review the output format">
    Open the generated file. It follows this structure:

    ````markdown
    # Project Summary

    <AI prompt description>

    ### `main.go`

    <File Info>

    ```go
    package main

    func main() {
        process()
    }
    ```

    ### `configure.go`

    <File Info>

    ```go
    package main
    // ...
    ```
    ````

    Each source file gets a `###` heading and a fenced code block with the correct language tag. You can paste the entire file into any AI chat or pipe it directly to another tool.
  </Step>

  <Step title="Common next steps">
    Once your first summary is working, explore the flags that are most useful day-to-day:

    **Print to STDOUT instead of writing a file**

    ```bash
    summarize -print
    ```

    Use this to pipe the summary directly to another command.

    **Limit to specific extensions**

    ```bash
    summarize -i go,ts
    ```

    Only files with `.go` or `.ts` extensions are included. The default include list is `go,ts,tf,sh,py,js,Makefile,mod,Dockerfile,dockerignore,gitignore,esconfigs,md`.

    **Start an AI chat session using the summary as context**

    ```bash
    summarize -chat
    ```

    `summarize` generates the summary and then opens an interactive AI session with your codebase loaded as context. The default provider is `ollama` with model `qwen3:8b`.

    **Summarize a different directory and write output elsewhere**

    ```bash
    summarize -d /home/user/work/project -o /home/user/summaries/project
    ```

    **Use a config file to avoid repeating flags**

    ```json
    {"i": "go,sh,ts", "d": "/home/user/work/project", "o": "/home/user/summaries/project"}
    ```

    ```bash
    export SUMMARIZE_CONFIG_FILE=/home/user/work/summarize.config.yaml
    summarize
    ```

    **Tune concurrency and output size**

    ```bash
    summarize -mf=100 -max=5000000
    ```

    `-mf` sets the maximum number of files processed concurrently (default: 369). `-max` sets the maximum output file size in bytes (default: 1,776,369).
  </Step>
</Steps>

<Tip>
Use `-print` to pipe the summary directly into other tools. For example: `summarize -print | pbcopy` copies the entire summary to your clipboard, or `summarize -i go,ts -print | llm "What does this codebase do?"` sends it straight to a CLI AI tool.
</Tip>
