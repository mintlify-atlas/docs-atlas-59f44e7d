Summarize is a Go CLI tool that recursively scans a project directory and consolidates your source files into a single, well-structured Markdown file. Run it in any repository to instantly generate a complete snapshot of your codebase — then optionally start an interactive AI chat session against that snapshot using Ollama or another LLM provider.

## How it works

<Steps>
  <Step title="Install the binary">
    ```bash
    go install github.com/andreimerlescu/summarize@latest
    ```
  </Step>
  <Step title="Run summarize in your project">
    ```bash
    cd ~/work/myproject
    summarize
    ```
    By default, summarize scans the current directory and writes a timestamped Markdown file to `./summaries/`.
  </Step>
  <Step title="View your summary">
    ```bash
    ls summaries/
    # summary.2025.07.29.08.59.03.UTC.md

    cat summaries/summary.2025.07.29.08.59.03.UTC.md
    ```
    Or print directly to STDOUT with `summarize -print`.
  </Step>
  <Step title="Start an AI chat session (optional)">
    ```bash
    summarize -chat
    ```
    Launches an interactive terminal UI powered by Bubble Tea. Ask questions about your codebase — the full summary is used as context for every response.
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="Concurrent processing" icon="bolt">
    Files are processed concurrently using Go goroutines and a configurable semaphore. Default: up to 369 files at once.
  </Card>
  <Card title="Flexible filtering" icon="filter">
    Include or exclude files by extension. Skip paths containing specific substrings. Ignore dotfile directories entirely.
  </Card>
  <Card title="Multiple output modes" icon="arrow-up-from-bracket">
    Write to a timestamped file, print to STDOUT, output as JSON, or compress with gzip — mix and match as needed.
  </Card>
  <Card title="Config file support" icon="file-code">
    Store your preferred settings in a YAML or JSON config file so you never have to type flags again.
  </Card>
  <Card title="Environment variable overrides" icon="sliders">
    Every major setting has an environment variable counterpart for CI/CD and shell profile use.
  </Card>
  <Card title="Cross-platform" icon="globe">
    Builds for macOS (Intel + Apple Silicon), Linux (amd64 + arm64), and Windows. One binary, every platform.
  </Card>
</CardGroup>

<Tip>
  Add `summaries/` to your `.gitignore` and `.dockerignore` to keep generated summaries out of version control.
</Tip>
