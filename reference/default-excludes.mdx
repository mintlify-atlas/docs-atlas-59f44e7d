---
title: "Default exclude list"
description: "File extensions and path patterns excluded from summaries by default"
---

`summarize` maintains two built-in exclusion mechanisms: a list of file **extensions** to skip (`-x` / `SUMMARIZE_EXCLUDE_EXT`) and a list of path **substrings** to avoid (`-s` / `SUMMARIZE_IGNORE_CONTAINS`). Both default to `useExpanded`, which resolves to the extended lists below at runtime.

<Warning>
Passing `-x` as a CLI flag replaces the default list entirely. This removes **all** built-in safety exclusions — secrets, private keys, binaries, and more will be included unless you re-add them manually. Prefer `SUMMARIZE_EXCLUDE_EXT` to append to defaults instead.
</Warning>

## Default avoided path substrings

The `extendedDefaultAvoid` list in `var.go` contains substrings that, if found anywhere in a file's path, cause that file to be skipped. This is controlled by `-s` / `SUMMARIZE_IGNORE_CONTAINS`.

| Substring | Skips |
|-----------|-------|
| `.min.js` | Minified JavaScript files |
| `.min.css` | Minified CSS files |
| `.git/` | Git repository internals |
| `.svn/` | Subversion repository internals |
| `.vscode/` | VS Code workspace settings |
| `.vs/` | Visual Studio solution files |
| `.idea/` | JetBrains IDE project files |
| `logs/` | Log directories |
| `secrets/` | Secrets directories |
| `.venv/` | Python virtual environments |
| `/site-packages` | Installed Python packages |
| `.terraform/` | Terraform state and providers |
| `summaries/` | The tool's own output directory |
| `node_modules/` | Node.js dependencies |
| `/tmp` | System temp directories |
| `tmp/` | Local temp directories |

## The `useExpanded` sentinel

Both `defaultExclude` and `defaultAvoid` are initialized to `["useExpanded"]` in source. At runtime this is replaced with the full extended lists above. You can pass the sentinel explicitly to restore the defaults after using a flag:

```bash
# Restore full default exclude list explicitly
summarize -x useExpanded

# Restore full default avoid list explicitly
summarize -s useExpanded
```

## Adding to exclusions

### Append via environment variable (recommended)

```bash
# Add extensions to the exclude list without replacing defaults
export SUMMARIZE_EXCLUDE_EXT=proto,graphql

# Add path substrings to skip without replacing defaults
export SUMMARIZE_IGNORE_CONTAINS=vendor/,generated/
```

### Replace with `-x` or `-s` flag

```bash
# Replace exclude list (drops all built-in exclusions)
summarize -x proto,graphql

# Replace avoid list (drops all built-in path filters)
summarize -s vendor/,generated/
```
